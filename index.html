How to play

Goal

Make the expressions on both sides of the equal sign have the same value. Normal order of operations applies; there are no parentheses.

Daily

Arrange the three digits on each side of the equation. Digits must stay within their assigned group. The operators are fixed, and the order of the operators on the right side is the reverse of the order on the left.

Challenge

Same rules as Daily, but with four digits on each side and three operators.

Bonus

The digits are fixed. Choose two different operators from the operator bank and place them in the blanks. Each placement is automatically mirrored on the other side so that the operator order is reversed. Solve as quickly as you can; your time is recorded when the equation becomes correct.

Moving pieces

Click a digit or operator to select it, then click where you want it to go. You can also select an already-placed piece and move it or swap it with another.

The game recognizes a correct equation automatically — there is no Submit button.

How help works

Show Values

This will calculate the value of each side of the equal sign. Values are only shown in Daily and Challenge modes if all digits in a group are placed. Values are only shown in Bonus mode when both operator slots are filled.

Hint

The first hint in Daily and Challenge modes tells you what kind of solution exists (e.g., an integer or a fraction with a denominator of 2, etc.). There are no hints in Bonus mode.

More Help

The second and final hint gives you the exact value of a valid solution for you to target (e.g., “One solution has a value of 10”).

The number of hints used appears in copied results.
